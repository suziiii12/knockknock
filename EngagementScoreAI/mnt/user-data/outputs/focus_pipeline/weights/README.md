# Pretrained Weights

## What runs automatically

Running `python download_weights.py` will:

1. Try to find a DAiSEE model on HuggingFace Hub (community uploads)
2. Fall back to generating **synthetic pretrained weights** if none found

The synthetic weights are trained on heuristic pseudo-labels that model
realistic focused vs. distracted behavioral patterns. They work well as
a starting point and can be fine-tuned on real DAiSEE data.

---

## Option A — Use the real DAiSEE dataset (recommended for accuracy)

1. **Request access** at:
   https://people.iith.ac.in/vineethnb/resources/daisee/index.html

2. Download and extract to `/path/to/DAiSEE/`

3. Fine-tune:
   ```bash
   python finetune_daisee.py --data_dir /path/to/DAiSEE --epochs 30
   ```

4. The fine-tuned weights will be saved to `weights/engagement_lstm_daisee.pt`

5. Update `pipeline/inference_engine.py` line:
   ```python
   WEIGHTS_PATH = Path(__file__).parent.parent / "weights" / "engagement_lstm_daisee.pt"
   ```

Expected accuracy on DAiSEE: ~55–65% (4-class engagement classification)
This matches published results for landmark-based models on this dataset.

---

## Option B — EmotiW pretrained features

The EmotiW 2020 Engagement challenge has publicly released model weights:
https://github.com/kaiwang960112/Self-Cure-Network

These use a different feature space (raw face crops, not landmarks),
but can be adapted as a teacher model for distillation.

---

## Option C — Self-supervised labeling (quickest)

Record yourself for 20 minutes:
- 10 min: actively coding/reading (label = engaged)
- 10 min: scrolling social media / phone (label = distracted)

Then run:
```bash
python self_label.py --record 20  # coming soon
```

This creates a small personal dataset and fine-tunes in ~5 minutes.
Personalized models typically outperform generic ones for focus detection.
